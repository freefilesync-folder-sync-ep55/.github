## Fast Folder Sync Brief

What is FreeFileSync? A desktop utility that compares folders and synchronizes their contents.  
Why use it for folder sync? The comparison lets you spot pending writes and deletions before committing.  
Who needs it? People who maintain working copies, external-drive copies, or shared folder pairs.  
Does it support file content comparison? Yes; it also offers faster comparisons that use metadata.  

## Folder Sync Overview

FreeFileSync makes it easier to see where two copies of a project have diverged. A photographer might use it to refresh a working copy on an external drive. A team might use it to compare two shared directories before a migration.

Pick the folder paths first, then run a comparison. A comparison method decides what counts as different, while the synchronization mode decides what to do about those differences. Read the proposed actions before writing anything to either side.

The comparison view shows what would change before anything is copied. If your goal is to recover older work, keep a separate backup rather than relying on a mirror as your only copy.

## Getting Started Playbook

Make two test folders with a few expendable files. Include a file that exists on only one side and a pair of files with different content. Keep the actual project out of the test pair until the results make sense.

Choose the test folders and compare them. Set the sync direction and inspect the actions, then synchronize the test pair. Compare the folders again to confirm the expected changes landed on the correct side.

## Everyday Use

The app does not require a login for a local folder pair. For recurrent jobs, save the configuration and confirm that the same external drive or share is mounted before opening it. Features such as filters and versioning are worth documenting alongside the job so that someone else can tell what the copy excludes.

## Practical Scenarios

Scenario A - External SSD copy: Check the drive label and compare before refreshing the destination.  
Scenario B - Two working copies: Examine files changed on both sides before choosing how to reconcile them.  
Scenario C - Generated folders: Exclude disposable build output from routine copies.  
Scenario D - Replaced documents: Direct versions to a separate location so they can be found after a run.
